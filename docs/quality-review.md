## 表記（用語集）

| 正 | 置き換えた語 |
|---|---|
| マップ | ボード、テーマボード、盤面（内部の名前・API のエラーはそのまま） |
| NOW | ピン、今の話題 |
| ハート（記号のボタンは ♡） | お気に入り、♡ する |
| 広げる | 展開 |
| 付箋 | メモ、配信メモ |
| お題 | キーワード、テーマ、きっかけ |
| このお題で始める | このお題で話題マップを作る |
| このマップを使う | コピーして使う |
| X に投稿 | X でポスト |
| 1つ戻る / 取り消すときは「1つ戻る」 | ひとつ戻る、やめるときは、元に戻すときは |

そのほか: 並べ方（設定。左下の「広げる」と名前が重なっていた）、閉じる（ダイアログの読み上げが英語の Close だった）、数の空白（8 つ・あと 3 秒・カード 12 枚）。

## 方針の判断が要るもの（未着手）

- X でシェアの本文を最初から文例で埋める（今は「文例を入れる」ボタン。自由入力を既定にした前の判断がある）
- いっしょに見るリンクを端末ごとに固定する（タブを閉じても同じ URL。複数タブで競合しうる）
- 終わった配信の URL を一覧に載せ続けない・YouTube のチャンネル URL を受け付ける
- 配信一覧の配信者名は、誰でも（他人の配信 URL でも）手で付けて載せられる（公開の文のフィルタは通す。本人の画面が次に知らせると戻る）。荒らしが出たら、名前を付けられるのを本人らしい場合に絞るか考える
- カードのダブルクリックで NOW（1 回目のクリックで広がるので誤操作の恐れ）
