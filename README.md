# TopicStream(ぬ)

雑談配信のための話題マインドマップです。キーワードを 1 つ入れると、3×3（マンダラート）で関連する話題が広がります。ログインや登録は要りません。

- 公式ページ: https://topic-stream.oshilog.life/
- キーなしデモ（AI の代わりに用意済みの話題で動きます）: https://nnhr-nunu.github.io/

## つかいかた

1. ホームでお題（キーワード）を入れて「始める」。思いつかないときはサイコロのボタン
2. 気になる話題をクリックすると、そこを中心に新しい 3×3 が広がる
3. 話す話題を **NOW**（今の話題）にして配信で使う。言いたいことは **付箋** に書いておく
4. 迷ったら **ルーレット**（`N`）。まだ話していないカードから次の話題を選ぶ

くわしくは [使い方ページ](https://topic-stream.oshilog.life/guide/) へ。

### コメントと連動する

マップ下の「配信と連携」に YouTube / Twitch の配信 URL を貼ると、コメントと連動します（Twitch はログイン不要）。視聴者が `1Eが聞きたい` のようにカードの番号を書くとそのカードが光ってハートが付き、`お題:〇〇` と書くと「お題箱」に届きます。

### 配信画面に映す

OBS のウィンドウキャプチャでブラウザを映すのが手軽です。マップ右上の「いっしょに見るリンク」をブラウザソースに入れると、手元の操作に合わせて動くマップだけを映せます。

### ショートカット

| キー | 内容 |
| --- | --- |
| `E` | 選んだカードを広げる |
| `N` | 話題ルーレット |
| `P` | 選んだ話題を NOW にする |
| `G` | 選んだカードだけ作り直す |
| `C` | 選んだカードの言葉をコピー |
| `R` | 新しいお題をマップに足す |
| `Z` / `Y` | 1 つ戻る / 進む |
| `+` / `-` | 拡大 / 縮小 |
| `0` | 全体を表示 |
