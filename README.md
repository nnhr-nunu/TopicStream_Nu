# TopicStream_Nu

雑談配信向けの話題マインドマップです。キーワードをクリックすると関連トークが放射状に広がります。配信者とリスナーが同じ画面を見ながら話せます。

自分のボードはブラウザ内だけに保存します。みんなのテーマボードといっしょに見るリンクは、小さな API（初期データ＋メモリ／一時ファイル）で動かします。ログインは不要です。

## 動かし方

必要: Node.js 20 以降

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:43173 を開きます。

本番ビルド:

```bash
npm run build
npm start
```

## 画面

| 画面 | URL |
| --- | --- |
| 自分のマップ | `/` |
| みんなのトークテーマ | `/community` |
| いっしょに見る | `/watch/（共有ID）` |
| OBS | `/overlay?transparent=1` |

## 使い方（配信中）

1. キーワードを入力するか、「ランダムなきっかけ」か「よく選ばれているトピック」から始める
2. ノードをクリックすると関連キーワードが約6個出てくる
3. しっくりこなければ **再生成**。**1つ戻る** / **進む** も使えます
4. ピンは「NOW」（いま話している）。箋箋はノードの横
5. 共有アイコンで「いっしょに見る」リンクをコピー。視聴者はマップを読めて、コピーとお気に入りだけできます

ショートカット: `E` 展開 · `G` 再生成 · `Z` 戻る · `Y` 進む · `R` ランダム · `P` ピン · `C` コピー

## Gemini APIキー

設定の API キーは **このブラウザの Local Storage にだけ** 保存します。サーバーには送りません。未入力・失敗時はオフライン生成です。発行: [Google AI Studio](https://aistudio.google.com/apikey)

呼び名（ニックネーム）も任意で、いっしょに見る画面に出ます。

## OBS オーバーレイ

| 項目 | 値 |
| --- | --- |
| URL | `http://127.0.0.1:43173/overlay?transparent=1` |
| 幅 | `1920` |
| 高さ | `1080` |

Custom CSS:

```css
body { background-color: rgba(0, 0, 0, 0); margin: 0; overflow: hidden; }
```

OBS の Browser Source は Chrome と Local Storage を共有しません。ライブで広げたいときはブラウザの `/overlay` をキャプチャするか、OBS の「対話」を使います。視聴者向けは「いっしょに見る」リンクを使ってください。
